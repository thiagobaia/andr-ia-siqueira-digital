# Andreia Siqueira Digital

Aplicacao React + Vite com roteamento via TanStack Router.

## Deploy no Coolify

Use o tipo de projeto Node.js (Nixpacks) com estes comandos:

- Install Command: `npm install`
- Build Command: `npm run build`
- Start Command: `npm run start`
- Porta da aplicacao: `3000`

O script `start` usa `vite preview --host 0.0.0.0 --port 3000`, pronto para publicacao no Coolify.
